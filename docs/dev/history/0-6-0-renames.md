# 0.6.0 renames

## Settings

The "*Sanity" suffix was dropped from all setting names
in favor of explicit "Shuffle *" / "Split *" names.
The plural form is now used for shuffled item collections.

| Old name | New name | - | Old YAML entry | New YAML entry |
|---|---| --- | --- | --- |
| NPC Sanity | Shuffle NPCs | - | `npc_sanity` | `shuffle_npcs` |
| Scarab Sanity | Shuffle Scarabs | - |  `scarab_sanity` | `shuffle_scarabs` |
| Shard Sanity | Shuffle XP Shards | - | `shard_sanity` | `shuffle_xp_shards` |
| Spirit Sanity | Shuffle Spirits | - | `spirit_sanity` | `shuffle_spirits` |
| Key Sanity | Shuffle Small Keys | - | `key_sanity` | `shuffle_small_keys` |
| Boss Key Sanity | Shuffle Boss Keys | - | `boss_key_sanity` | `shuffle_boss_keys` |
